# DUN · 史前动物博物馆

DUN 是一座面向 2–6 岁孩子与家长的开放式史前动物博物馆。它鼓励共同观察、轻声讲述和屏幕之外的对话，不设置输赢，不自动播放，也不依赖广告或行为追踪。

项目目前已经建立产品原则、可运行的博物馆入口和首个完整的三角龙展品。

3D 动物展示、原创背景、素材授权与后续展品入馆流程统一遵循
[互动史前动物博物馆技术方案](docs/MUSEUM_TECHNICAL_PLAN.md)。

## 本地开发

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

验证全部质量门：

```bash
npm run typecheck
npm run lint
npm test
```

## 项目原则

- 亲子共同使用，而不是把孩子独自留给屏幕
- 默认安静：无自动播放、无突发音效、尊重减少动态效果设置
- 无账户、广告、行为追踪和游戏化排名
- 儿童内容与代码都必须有清晰、可追溯的来源和授权
- 每个功能由公开 Issue 定义，以证据验证后才合并
